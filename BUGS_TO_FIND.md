# Starter Code – Debugging Exercise

The code in this folder is intentionally defective. It is a compact simulation of a backend API containing security, correctness, validation, and performance problems.

Use the source and the bug report in `docs/DEBUGGING_REPORT.md` to compare the initial implementation with the corrected implementation. The corrected, runnable project is in the `fixed/` folder.

Known areas to investigate (not the exact answers):
- Authentication and credential storage
- SQL query construction and database workload
- Resource ownership and request validation
- Referential integrity and missing-resource handling
- Test coverage and repeatable verification

Do not deploy or use the starter API with real user data. It is intentionally insecure.
